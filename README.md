## Why it interests me

This article interests me because I find LLMs really fascinating. It's cool how OpenAI Astra hides its reasoning, using engineering explanations instead. I also found the technique of reusing layers several times per token very insightful as well. My favorite part about the article was the cost trade off between inference and compute. By sharing weights across loops, OpenAI is able to cut memory but not compute. This is directly applicable to some of the stuff I'm doing outside of school, leading to my interest in this article.
